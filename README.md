# Koopman-MARL Trading Framework

A research framework for algorithmic trading using:

- Deep Reinforcement Learning
- Multi-Agent Reinforcement Learning
- Koopman Operator Representation
- Nonlinear Market State Modeling


## Project Goal

Develop a novel DRL framework for financial markets by combining:

1. Koopman-based latent state representation
2. Multi-agent reinforcement learning
3. Risk-aware trading policies
